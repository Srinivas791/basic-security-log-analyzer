About the Security Log Analyzer Project

BUILDERS Phase 2 - Defensive cybersecurity architecture, ethical constraints, and MITRE ATT&CK alignment.

1. Project Objective & Domain Overview

Cybersecurity / Defensive Security

The Basic Security Log Analyzer is a specialized defensive cybersecurity application engineered to ingest fictional and sanctioned public authentication streams, detect malicious login patterns, identify targeted brute-force attacks, and isolate unusual velocity bursts inside sliding temporal windows.

Operating entirely within the defensive security paradigm, the system surfaces threat intelligence without disrupting operational services, enabling Security Operations Center (SOC) analysts to swiftly prioritize incident response, configure edge perimeter rate limits, and enforce identity governance.

2. Defensive Security Requirements & Ethical Safeguards

Strict Compliance

Zero Credential Harvesting

The analyzer strictly parses usernames, timestamps, statuses, and network source IPs. Real passwords or secret hashes are never requested, inspected, or persisted.

RFC 5737 Compliant Fictional IPs

All sample logs utilize sanctioned RFC 5737 documentation ranges (192.0.2.0/24, 198.51.100.0/24, 203.0.113.0/24) and RFC 1918 private subnets, ensuring no real-world entities are targeted.

Non-Disruptive Observability

The system does not lock accounts or mutate directory infrastructure automatically, functioning strictly as an audit, forensic, and decision-support tool for defensive teams.

3. MITRE ATT&CK Framework Mapping

Tactics & Techniques
Technique ID Technique Name Observed Attack Pattern Defensive Detection Mechanism
T1110.001 Password Guessing / Brute Force Consecutive failure sequences targeting privileged accounts ('admin', 'root'). Configurable threshold accumulator tracking failures by username in failed_login.py.
T1110.003 Password Spraying Single origin IP attempting logins across multiple distinct usernames in rapid sequence. Multi-target cardinality detection per IP address flagging "SPRAY BOT" indicators.
T1110.004 Credential Stuffing Velocity Automated bot suites generating high-frequency authentication bursts (> 5 attempts / 30s). Sliding window temporal clustering algorithm implemented in burst_detector.py.

4. System Architecture & Modular Composition

Python Modular Engine
main.py

Flask server routing, session dataset management, REST API endpoints, and template rendering integration.

log_parser.py

Resilient ingestion of .txt and .csv files, multi-pattern regex timestamp extraction, and fault-tolerant separation of malformed rows.

failed_login.py

Aggregation of unsuccessful logins by username and IP, dynamic threshold filtering, and severity grading.

burst_detector.py

Sliding-window temporal analyzer detecting anomalous surges, calculating velocity per minute, and clustering burst spans.

report_and_tests.py

Multi-format security audit generator (JSON/CSV/Text), posture calculation, and 5 automated verification test cases.

sample_logs.txt / .csv

Fictional authentication records featuring benign logins, targeted brute-force attacks, bursts, and malformed records.
